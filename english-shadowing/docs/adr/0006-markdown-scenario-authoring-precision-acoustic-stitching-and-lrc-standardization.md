# ADR-0006: Markdown Scenario Authoring, Precision Acoustic Stitching, and Full Enhanced LRC Standardization

- **Status:** Accepted
- **Date:** 2026-09-20
- **Scope:** `english-shadowing`

---

## 1. Context & Problem Statement

In previous iterations of the English Shadowing Player:

1. **Short Scenarios**: Curated scenarios were short (~5–7 lines, ~20–30 seconds), preventing extended listening immersion and deeper shadowing drills.
2. **Audio/LRC Desynchronization & Cumulative Drift**: In `scripts/generate-scenario-audio.py`, inter-turn pauses (0.4s) were added mathematically to the LRC timeline without actually injecting silence bytes into the stitched MP3 audio stream. Over longer 1–5 minute tracks, the subtitle highlighting drifted progressively behind the audio.
3. **Naive Word Timing**: Intra-sentence word timings were divided strictly by character length (`len(word) / total_chars * duration`), ignoring syllable weights, short function words (e.g. "a", "the", "in"), and punctuation pauses.
4. **Duplicate Subtitle Formats & Code Clutter**: The codebase maintained both `.srt` and `.lrc` files in `english-shadowing/audio/` and duplicate `lrcContent` / `srtContent` keys in `CURATED_SCENARIOS`. Since Enhanced LRC contains full line timestamps, translations, and word-level karaoke tokens (`<mm:ss.xx>word`), `.srt` was redundant for bundled scenarios.
5. **Rigid Hardcoded Scenarios**: Scenarios were hardcoded inside Python scripts, making it cumbersome for LLMs or human authors to generate, expand, and maintain rich 1–5 minute dialogues.

---

## 2. Decision Drivers

- **Token-Efficient, Natural Scenario Authoring**: Enable LLMs and human content designers to create multi-speaker dialogues and monologues using clean Markdown (`.md` with YAML frontmatter) with zero syntax escaping errors.
- **Zero Cumulative Audio/LRC Drift**: Guarantee millisecond-accurate alignment between the stitched MP3 audio track and Enhanced LRC subtitle cues across long 1–5 minute tracks.
- **Natural Intra-Sentence Karaoke Timing**: Enhance word highlight pacing using syllable- and punctuation-aware weighting anchored to exact sentence audio offsets.
- **Single Source of Truth (Enhanced LRC)**: Deprecate bundled `.srt` files and standardize 100% on Enhanced `.lrc` for bundled scenarios and player state while retaining a backward-compatible parser for legacy custom `.srt` uploads.
- **Universal Browser Compatibility**: Deliver Voice-Optimized MP3 (24kHz Mono 48kbps) by default for universal, zero-latency playback across iOS Safari, Android Chrome, and Desktop PWA, with a CLI option for Opus/WebM encoding.
- **Modular Directory Architecture**: Structure scenarios in dedicated folders (`english-shadowing/scenarios/<scenario-id>/`) containing source Markdown, generated audio, and subtitles.

---

## 3. Considered Options & Decision Outcome

### A. Scenario Authoring Format: Markdown (`.md` with Frontmatter) vs YAML vs JSON

- **Option 1 (JSON)**: Traditional JSON structure with nested dialogue arrays. High token overhead (~2x Markdown) and prone to quote/comma escaping errors in long LLM outputs.
- **Option 2 (YAML)**: Structured YAML files. Readable, but indentation-sensitive for long 40-turn dialogues.
- **Option 3 (Chosen - Markdown with Frontmatter)**:
  - YAML frontmatter defines metadata (`id`, `title`, `category`, `level`, `accent`, `speakers` voice mappings).
  - Body supports natural multi-speaker dialogues (`**Speaker**: text \n > translation`) and single-speaker monologues (`text \n > translation`).
  - Highly token-efficient (~35% fewer tokens than JSON) and natively generated by LLMs without formatting failures.
  - _Outcome_: Chosen as the single source of truth for scenario authoring.

### B. Audio Synthesis & Silence Stitching Engine

- **Option 1 (Status Quo)**: Per-sentence TTS byte concatenation without silence injection.
- **Option 2 (Single-Pass SSML)**: Generate single SSML with `<voice>` and `<break>` tags. (Fails because Edge TTS free endpoint rejects or corrupts multi-voice switching inside single SSML documents).
- **Option 3 (Chosen - Precision Acoustic Stitching & Syllable-Weighted LRC)**:
  - Synthesize each dialogue turn individually with Edge TTS using its assigned neural voice (`en-US-AvaMultilingualNeural`, `en-US-AndrewMultilingualNeural`, `en-GB-SoniaNeural`, etc.).
  - Extract exact sentence audio duration from Edge TTS `SentenceBoundary` stream metadata.
  - Insert exact synthetic MP3 silence frames (500ms between speaker turns, 300ms intra-speaker) into the combined audio stream matching LRC pause offsets.
  - Compute intra-sentence word timings with syllable- and punctuation-aware weighting (discounting fast articles, adding explicit pauses for commas and periods), anchored to exact sentence offsets.
  - _Outcome_: Chosen. Completely eliminates cumulative drift and delivers natural karaoke highlighting over 1–5 minute tracks.

### C. Subtitle Format Standardization: Full LRC Standardization

- **Option 1**: Retain both `.srt` and `.lrc` side-by-side.
- **Option 2 (Chosen - Full LRC Standardization)**:
  - Delete all bundled `.srt` files from `english-shadowing/audio/`.
  - Remove `srtContent` from `CURATED_SCENARIOS` in `english-shadowing/index.html`.
  - Standardize 100% on Enhanced `.lrc` for all bundled scenarios, karaoke timing, and bilingual translations.
  - Retain `parseSrt()` in `index.html` exclusively as a backward-compatible fallback for user-uploaded custom `.srt` files in the import modal.
  - _Outcome_: Chosen. Simplifies architecture, removes redundant files, and reduces bundle size.

### D. Scenario Directory Organization & CLI Tooling

- **Structure**:
  ```text
  english-shadowing/scenarios/
  ├── specialty-coffee/
  │   ├── scenario.md
  │   ├── audio.mp3
  │   └── subtitles.lrc
  ├── tech-standup/
  │   ├── scenario.md
  │   ├── audio.mp3
  │   └── subtitles.lrc
  ├── ...
  ```
- **CLI Commands**:
  - `python3 scripts/generate-scenario-audio.py --scenario <id>`: Generate a single scenario.
  - `python3 scripts/generate-scenario-audio.py --all`: Generate all scenarios.
  - `python3 scripts/generate-scenario-audio.py --dry-run`: Validate schema and timing without network calls.
  - `python3 scripts/generate-scenario-audio.py --sync-only`: Fast compilation of `CURATED_SCENARIOS` into `index.html`.
  - `bun run audio:shadowing` and `bun run audio:shadowing:sync` shortcuts in `package.json`.

---

## 4. Consequences

### Positive

- **Rich 1–5 Minute Practice**: Learners gain access to deep, authentic, multi-turn dialogues and monologues across CEFR A2 to C1 levels.
- **Sub-Millisecond Synchronization**: Zero audio/LRC drift across long tracks and natural karaoke word lighting tempo.
- **Token-Efficient LLM Pipeline**: Instant generation of new high-quality scenarios from markdown prompts.
- **Cleaner Codebase**: Deletion of legacy `.srt` files and unified Enhanced LRC data model.

### Negative / Trade-offs

- Running audio generation for all 6 scenarios requires internet connectivity to communicate with Edge TTS (cached generated `.mp3` and `.lrc` assets are committed to the repo for zero-backend offline PWA execution).
